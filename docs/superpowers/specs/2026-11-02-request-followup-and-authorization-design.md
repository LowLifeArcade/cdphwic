# Request follow-up and State-Issued Formula Authorization

## More Info Requested

Place the section immediately after Health Care Provider and before State-Issued Formula Authorization. CDPH/WIC and Admin can enter notes and click **Send to LA**. Sending requires nonblank notes and saves the notes, sender, and timestamp together with the request status. Show **Pending LA** in the request header and Requests list, using the existing `needs_info` state. Notify only the request's local agency in the app. Preserve each round of requested corrections and responses.

Recommended return workflow: the local agency sees the notes, updates the existing request and, when needed, replaces its medical documentation. Save permits incomplete corrections; **Resubmit** validates required fields and sends it back to CDPH/WIC for review. Keep request identity, prior review history, issuance, and shipment records. Local Agency cannot edit state issuance, reviewer notes, or shipment plans. Pending LA must not be silently cleared by receipt or shipment actions.

Confirmed by user: Local Agency can edit, replace documentation, Save incomplete corrections, and Resubmit the complete request.

## Send ETA and authorization document

After a successful Send ETA or Send Update, notify the receiving local agency in the app and provide **Print / Download Authorization** to both the reviewer and receiving agency. Use the same behavior for distributor shipments and local agency transfers. An ETA sent for a transfer does not confirm physical shipment or receipt.

Recommended document behavior: save a version of the authorization data with each sent ETA so the printable record matches what was communicated. Do not include private, unsent shipment drafts. The request displays the latest sent version; earlier versions remain available in history. Sending a later shipment includes previously published shipment information and identifies its formula.

## Printable form

Title: **State-Issued Formula Authorization**. Use a simple, legible US Letter layout with repeated request identification and page numbers when content requires more than one page.

Include:

- Local agency name, representative/contact details, and selected Shipping Address including Attn:.
- Request number/type, submission and authorization dates, participant name and identifiers, participant details, prescribed formulas, diagnoses, food restrictions, and health care provider details.
- Issuance for each of up to two formulas: name, form, flavor where relevant, benefit months and quantities, approved cases/months, and relevant units on hand/surplus values.
- Shared Next Steps text in full.
- Published shipment details for each formula: source, cases and Unit(s), ETA, carrier, and tracking numbers.
- At the end, **Signature(s) Confirming Receipt of Formula (Single Issue Only)** with three rows, Month 1, Month 2, and Month 3. Each row has a Parent/Guardian signature line and date line. Keep the signature block together.

A sample supplied by the user will guide final formatting. If no sample is supplied, create a clean draft using the app's approved blue palette and provide a PDF preview for review.
