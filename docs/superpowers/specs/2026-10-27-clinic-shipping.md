# Clinic shipping
Agency address books store clinic name, street address, city, state, ZIP, and optional unit/address line 2. Local Agency members manage their own agency; Admin manages any agency. CDPH/WIC can read authorized agencies but cannot maintain addresses. Manual entry and CSV/XLSX import add addresses; existing entries can be edited or archived. Archived addresses remain in existing request snapshots.

New Request gets Shipping before Additional Information. Clinic address and Attention (local agency rep) are required to Submit but incomplete Save remains available. Agencies see their own clinics. Admin selects an agency and then its clinics. A New address option allows direct typed shipping details; it does not silently add to the shared address book. Saved-address submissions are checked against agency ownership and use the canonical server address snapshot. Drafts and pre-review edits retain shipping. Details display Shipping to reviewers. Existing submitted requests are not retroactively rejected unless their original form is edited and resubmitted.
